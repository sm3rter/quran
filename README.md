# إذاعة القرآن الكريم

تطبيق ويب لتشغيل إذاعة القرآن الكريم بث مباشر، ويعمل على الهاتف والحاسوب.

الرابط: https://sm3rter.github.io/quran

## عن المشروع

هذا المشروع لوجه الله تعالى، وصدقة جارية. نسأل الله أن ينفع به.

المشروع غير مخصص للاستخدام التجاري.

البث الصوتي ملك لمصدره الأصلي، وليس لهذا المشروع أي حق فيه.

## طريقة التثبيت

### آيفون

1. افتح الرابط في متصفح Safari.
2. اضغط زر المشاركة.
3. اختر إضافة إلى الشاشة الرئيسية.
4. اضغط إضافة.

### أندرويد

1. افتح الرابط في متصفح Chrome.
2. اضغط على قائمة المتصفح.
3. اختر تثبيت التطبيق أو إضافة إلى الشاشة الرئيسية.
4. افتح التطبيق من الشاشة الرئيسية.
